# Security

This release is an experimental local reference, not a production security boundary. Only the latest main-branch reference is maintained; no support SLA is promised.

Report vulnerabilities privately through GitHub's **Report a vulnerability** feature when enabled for this repository. If it is unavailable, use the contact route on https://a2zsoc.com and request a private channel before transmitting details. Do not publish credentials, exploit details against a live community, or customer data in an issue.

Useful reports include affected revision, a synthetic reproduction, expected boundary and observed behavior. Do not test against CNCF or any third-party workspace without written authorization.
