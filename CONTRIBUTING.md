# Contributing

Reproduce an issue with public or synthetic data and open a focused issue or pull request. Do not include credentials, customer contracts, consent receipts, private messages or identifying incident details. Use the security reporting instructions for vulnerabilities.

Run `python scripts/evaluate.py` and `python scripts/publication_check.py` before submitting. Add meaningful tests for changed permission, evidence, metric or loop behavior. Do not describe a mocked provider as a live integration or turn an unmeasured metric into zero.

Preserve upstream attribution. Contributions must not add automated outreach, private-channel/DM ingestion, implicit consent, arbitrary MCP tool dispatch or automatic production promotion. Propose a separate reviewed design for new capabilities.

Explain the problem, resulting behavior, validation and known limitations. By submitting an original contribution for inclusion, you agree to license it under this project's Apache-2.0 license. Third-party material must retain its original licensing information.
