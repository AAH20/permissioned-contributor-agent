# CNCF community policies and project boundaries

This project is independent and not endorsed by CNCF. CNCF is an example contributor community; its name does not convey authorization to use its infrastructure.

`policies/sources.json` records immutable source URLs and content hashes for the four policies consulted during the initial pilot. Documents are linked, not relicensed or redistributed here.

| Source | Interpretation for this project |
|---|---|
| [Slack Guidelines](https://github.com/cncf/foundation/blob/25b83988f0e5f6b9a5594a44f8d9db3d37cdf19e/policies-guidance/slack-guidelines.md) | No channel spam or unsolicited private commercial/recruitment solicitation. The project is stricter: no automated outreach of any kind. |
| [Community Code of Conduct](https://github.com/cncf/foundation/blob/25b83988f0e5f6b9a5594a44f8d9db3d37cdf19e/code-of-conduct.md) | Respect participants and privacy; no profiling or automated conduct adjudication. |
| [Jurisdiction policy](https://github.com/cncf/foundation/blob/25b83988f0e5f6b9a5594a44f8d9db3d37cdf19e/code-of-conduct/coc-committee-jurisdiction-policy.md) | Appropriate human responders handle concerns; project jurisdiction matters. |
| [Incident resolution](https://github.com/cncf/foundation/blob/25b83988f0e5f6b9a5594a44f8d9db3d37cdf19e/code-of-conduct/coc-incident-resolution-procedures.md) | Incident handling stays outside contributor matching; no reports are ingested here. |

The [CNCF policy index](https://www.cncf.io/policies/) additionally links brand, political-neutrality, intellectual-property and antitrust policies. This is a scoped reference pack, not an exhaustive policy inventory. Review current versions and the individual project's contribution rules before acting.

Publicly readable content is not blanket permission to profile community members or reuse their activity for commercial diligence. Contributor discovery, supplier evaluation and contract management require separate consent and data boundaries.
